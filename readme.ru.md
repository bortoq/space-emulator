# Позиционное адресное пространство (определение)

Это полуинтервал однотипных значений. Каждый полуинтервал пространства
адресуется либо позициями, ограничивающими интервал (адресация vm1,
границы строго больше и строго меньше), либо меньшей позицией
полуинтервала и размером интервала (адресация vm2, младшая граница входит
в полуинтервал, старшая строго больше полуинтервала). Полуинтервалы
одного размера можно копировать (нарушать изоляцию* одних значений
другими), т.е. выполнять присваивание значения одного полуинтервала
другому.

space-emulator — механизм vm2 адресации битовых значений.

Между адресными пространствами можно выполнять копирование.

Каналы — это тоже позиционно адресуемые значения, но они
отличаются от остальных значений пространства тем, что имеют другой тип.
Из этой одной позиции можно прочитать уже не бит, а куда большую величину.
